# История проекта

## v0.5.1 — аудит надёжности и исправления (2026-10-25)
- Регрессионные проверки для импорта, сетевых ответов, прогнозирования и планировщика; 40 проходящих тестов.
- Ограничение размера REST JSON и HTML применяется при потоковом чтении, до полного накопления ответа в памяти.
- Общая блокировка обновления данных между API и отдельным планировщиком (PostgreSQL advisory lock; локальная блокировка SQLite).
- API-контейнер получил отдельный writable volume для официальных XLSX при ручном обновлении; корневая ФС остаётся read-only.
- Исправлен поиск последних запусков ежемесячного планировщика в отчёте качества.
- Отбрасываются конфликтующие наблюдения в одном пакете; точные дубликаты не увеличивают счётчики.
- Проверяется конечность значений прогноза; CSV-выгрузка защищает текстовые ячейки от формул в табличных редакторах.
- Примечание: это усиленный пилотный код; перед внешней эксплуатацией остаются обязательными проверки из `docs/BANK_DEPLOYMENT_CHECKLIST.md`.

## v0.5 — пилотное банковское усиление (2026-10)
- API качества статистики: свежесть, пропуски месячных рядов, взаимная сверка источников, тип офлайн-снимка.
- Система происхождения: SHA-256 принятых файлов/JSON/обзоров; различаются online, cache, local, offline snapshot.
- История исправлений наблюдений: старое/новое значение, месяц, ссылка на `sync_run_id`; закрытая админ-точка доступа.
- Планировщик, изолированный от API: запуск с 5-го числа, повтор частично неуспешного обновления раз в 6 часов, PostgreSQL advisory lock, история запусков.
- При production-конфигурации обязателен длинный административный токен; Swagger скрыт, админ-операции защищены, общедоступные логи редактируются.
- Контейнеры с отдельным непривилегированным пользователем, read-only FS, SQL healthcheck, localhost-only API, отдельный PostgreSQL.
- Защита от слишком больших выгрузок, ZIP bombs, посторонних API-хостов/редиректов, некорректных чисел.
- Документация пилотного развёртывания, приёмочный чек-лист и дополнительный test suite (31 тест).



## v0.4 — продуктовый интерфейс и прогноз
- Единая навигация по страницам вместо перехода на сырой JSON, вкладки: Overview, Regions, Forecast, Updates.
- Plotly локально: zoom/pan, диапазон по времени, управление графиком, экспорт PNG.
- Региональные KPI, MoM/YoY, YTD, 12-месячные средние.
- Наивная сезонная, скользящая и трендовая прогнозные модели, backtesting, диапазоны и пользовательские сценарии.
- Фоновая загрузка при старте и ежедневная повторная проверка, журнал ошибок и повторное использование локального официального XLSX при сетевом сбое.
- Дополнительные API, тесты и рекомендации по безопасности администратора.
