# Приёмочный чек-лист v0.4

1. После обновления сохранён старый файл `mortgage.db`; `/api/v1/health` показывает ранее загруженные ряды.
2. `python -m pytest -q` завершился успешно.
3. Открыть `/`, перейти по всем пяти пунктам меню (Swagger — отдельная страница). Нет JSON на странице «Журнал обновлений».
4. В разделе «Обзор рынка» переключить ряд, приблизить 2024 год, сдвинуть диапазон, вернуть весь период, скачать PNG и CSV.
5. В «Регионах» сменить период, валюту, два субъекта; убедиться, что значения и график обновились. Проверить отсутствие РФ и федеральных округов в рейтинге субъектов.
6. В «Прогнозировании» выбрать РФ, `total`, 3 месяца, базовый прогноз, затем стресс −3%; сравнить прогнозные значения, не историю. Проверить MAE и имена моделей.
7. В «Журнале» должен быть хотя бы один запуск фонового импорта после старта сервера; при недоступном ЦБ в колонке «Детали» указана ошибка. Кнопка обновления запускает фоновую задачу без блокирования интерфейса.
8. При закрытом интернете и наличии скачанного кэша `downloads/cbr_volume.xlsx` новые базы могут заполниться из него, не теряя данные при неудачном HTTP.
9. Источники на графиках реальны, синтетические примеры помечены `demo`. В прогнозе указано, что это не официальный прогноз.
10. Провести тест на исходном XLSX из Банка России на пользовательском компьютере; только после этого считать сетевую региональную интеграцию проверенной end-to-end.
