# Исследование прогнозирования ипотечного рынка — план v0.5

## Исследовательский вопрос

Можно ли улучшить точность месячного прогноза объёма ипотечных выдач по регионам РФ, добавив макроэкономические факторы, причём без утечки сведений, опубликованных позднее момента прогноза?

## Данные

1. Ипотечные выдачи по регионам — существующий региональный XLSX Банка России, объём в млн руб., 2019–2026.
2. Ключевая ставка — официальный ряд ЦБ: https://www.cbr.ru/hd_base/keyrate/ (доступен исторический ежедневный ряд). Агрегация по месяцу: среднее, последнее известное на день прогнозирования, лаги 1/3/6 месяцев.
3. Средневзвешенная ставка по ИЖК и число выданных кредитов — официальные региональные таблицы ЦБ https://www.cbr.ru/statistics/bank_sector/mortgage/ . **Прежде нужно верифицировать форматы Excel**, не переносить структуру из файла объёмов вслепую.
4. Инфляция (ИПЦ), реальные доходы — Росстат; при интеграции учитывать дату публикации и пересмотры значений.
5. Ипотечные программы поддержки: периоды действия / даты объявления брать только из опубликованных нормативных документов. Нельзя приписывать коэффициенты влияния событиям без каузальной идентификации.

## Модели для сравнения

- Сезонный наивный (обязательный benchmark)
- Дампированный тренд/сезонная экспоненциальная сглаженная модель (Holt–Winters)
- SARIMA/SARIMAX с лагами проверенных экзогенных факторов
- CatBoost на лаговых признаках и календарных фичах (если улучшение статистически устойчиво)

Документация: https://www.statsmodels.org/stable/generated/statsmodels.tsa.holtwinters.ExponentialSmoothing.html ; https://skforecast.org/latest/introduction-forecasting/introduction-forecasting

## Строгая проверка

- Sliding/expanding window по месяцам: каждый обучающий срез заканчивается раньше валидационного периода.
- Минимум 24–36 месяцев до первого бэктеста; evaluation горизонтов отдельно для 1, 3, 6 месяцев.
- MAE, RMSE, sMAPE (осторожно при нулях), сезонная MASE, coverage 80% интервальных прогнозов.
- Отдельная проверка по РФ и по регионам с разной величиной и изменчивостью выдач.
- Любое утверждение, что модель точнее baseline, допустимо только после количественной проверки.
- Перед каждым прогнозом строго использовать только значения факторов, уже публично доступные к дате формирования прогноза.
- При неизвестных будущих значениях ключевой ставки выдавать отдельные условные сценарии; не изображать их историческими фактами.

## Ограничения текущей v0.4

Текущий прототип использует только объёмы ипотечных выдач. Реальные макроэкономические ряды пока не интегрированы. Три упрощённые модели предназначены для прозрачного MVP и не являются научно валидированной прогнозной системой. Интервал неопределённости эвристический, а бэктест одношаговый.
